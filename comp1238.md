## Week 1 - Historical Introduction to Text and Writing
- Pre-Writing was 30,000 years ago: Cave paintings
- First writing was 5,000 years ago: Clay tablets in Mesopotamia
- Early printing techniques were cylinder seals used in Mesopotamia for stamping
- The modern writing systems of the alphabet

## Week 2 - Representing Text and Numbers in Computers
- Binary System which has bits - binary digits represents one of two states (0 or 1).
- Bye is a group of 8 bits 00000000 = 0 00000001 = 1
- Binary Numbers are numbers represented by using base 2
- Different memory types volatile memory, non-volatile memory which retains data without power.
- Number representation with ranges from 0 - 255 for 8 bits
- Signed numbers range from -128 to 127 for 8 bits
- Fractional numbers represented using scientific notation with two integers

## Week 3 - Structure of Text
- Key concepts are lines and indentation they are fundamental in coding - also indentation helps in visual understanding of the code
- Markup Languages > Markdown which has simple syntax for formatting
- Titles: # Title. ## Subtitle
- Italic: _italic_
- Bold: **bold**
- Lists: * item or - item
- Rendering: Conversion from raw text to formatted view
- HTML: More verbose than markdown (Tags): <ul>, <li>, <p>, <strong>, <h1>, <h2>, <h3>
- Special characters such as non-alphanumeric symbols @, #, $, &, *.
- Examples for this would \# to display # in Markdown

## Week 4 - Manipulating Text and Text Editors
- Keyboard mastery is very important, efficient typing reduces cognitive load.
- Types standard 104 key layout, variants of split, vertical and ortholinear keyboards.
- Text editor types: Word processors like Microsoft Word vs Text Editors like NotePad
- Popular editors Vim: command line based and requires learning the commands - exit command :q!
- Visual Studio Code (VS Code) Widely used feature rich and extensions and themes are avaiable
- IDE's: Integrated Development Environments like Webstorm, Pycharm.
- Search Techniques basic search use Ctrl + F for finding text, advanced search technique wildcard symbol * for any character sequence
- Regex (Regular Expressions): for pattern matching. example line\d+ finds "line" followed by digits.

## Week 5 - Command Line Interfaces
- Modern CLI Usage advantages: some functionalities are only available via CLI
- Faster for certain tasks compared to graphical interfaces
- Easier automation through scripting
- Efficient for remote work with low bandwidth requirements
- Minimal resource usage on computers.
- Basic CLI Commands
- ls: List files in a directory.
- cd: change directory
- pwd: print working directory
- less: view file contents interactively
- cp: copy files
- mv: move files
- mkdir: create a directory
- ping: test network connectivity
- Advanced CLI commands
- grep: search text using patterns
- redirection and piping: direct output to files or other commands.
- **Remote Access and Security**
- SSH (Secure Shell)
- Connect to remote computers securely
- Allows command line access to remote systems
- File transfer: scp securely copy files between computers.
- sftp : secure file transfer protocol.
